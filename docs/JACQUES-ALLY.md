# 友军雅克：圣殿誓约

状态：已实装（2026-11-15）。生成器 `_tools/add_jacques_ally.py`（友军本身）、`_tools/add_ally_units.py`（敌方技能接入友军）。

用户的要求：打败雅克之后，可以召唤雅克短暂出现（20 秒）帮你一起战斗；其他 Boss 和数据包里的怪物也能索敌到他，就像一个玩家单位一样。

用户定下的三点：
1. 召唤方式：道具「圣殿誓约」，右键召唤，冷却 3 分钟，可反复使用。
2. 索敌范围：原版 AI 加上全部 Boss / 怪物技能都把他当目标。
3. 他能被打死：生命 100。

## 1. 道具

- 「[传说] 圣殿誓约」：右键吹号。贴图 `rpg:item/jacques_oath`（32×32）：原作《地下城》的风之号角（`SM_WindHorn` + 它的 32×32 像素贴图 `T_Windhorn`），逐个像素换成圣殿配色（象牙白号身、金色吹嘴、圣殿红的箍与背带），按原作物品图标的角度渲染成像素图，不是重画（`_tools/jacques_ally_ref/make_oath_icon.py`，一次性）。
- 击败雅克时，战场里每个还没有誓约的人各得一件（`rpg:jacques_ally/reward`，由雅克战的胜利结算调用）。
- 冷却 3 分钟：自己的计分（`rpg_al_cd`，到期的游戏刻），冷却中右键会提示还剩几秒；物品上同时带原版 `use_cooldown`（冷却组 `rpg:jacques_oath`），客户端会显示冷却遮罩。
- 右键实现沿用本包的做法：`consumable`（永远吃不完）+ `using_item` 进度触发；按住时每刻都触发，只认按下的第一刻。

## 2. 友军雅克

- 载体是铁傀儡：原版里僵尸、骷髅、蜘蛛、掠夺者、劫掠兽、史莱姆等都会主动攻击铁傀儡，所以原版怪物天然会锁定他。
  - `NoAI`，缩到 0.7407 倍：高 2.0，和卫道士的乘客挂点相同，雅克外观的部件不用另调。
  - 外观用雅克 Boss 的同一套（`rpg.jqwear`）：`LordLook` 新增 `carrier_type`，雅克的外观不再限定卫道士载体。
  - 隐身，名字不显示（原版不给隐身生物画名字）。
- 生命 100、护甲 8。副手藏一件死亡保护：致命一击被它吃掉 → 他倒下（原作倒地动作）→ 1.5 秒后消失；倒下期间敌人不再把他当目标。
- 玩家误伤：玩家打到他时（`player_hurt_entity` 进度）把生命补回上一刻。玩家武器和技能的范围伤害本来就避开他（见 §3）。
- 行动全部由函数驱动：
  - 找 20 格内最近的敌人（封印用的敌怪表，含隐身的 Boss 载体；不打苦力怕、不打无敌的）。
  - 走过去，每刻 0.3 格，能上一格台阶，自己做重力。
  - 贴身（3.2 格）时出坟墓克星三连：下劈 9、再劈 9、横扫 12（范围）。
  - 6～22 格时偶尔端起竖琴弩，上弦四段后放一道金色弩光，伤害 8。
  - 没有敌人时跟着召唤他的人，离开 24 格就直接跟上。
- 伤害都算「他打的」（`by` 友军本身），被打的怪物会回头打他：他是真正的诱饵。代价是他打死的怪不算玩家击杀。
- 20 秒到前 2 秒说一句「时候到了」，到时在光柱里离开。
- 特效与 Boss 战一阶段同色：登场光柱、红十字圣印、光环，下劈双层弧光，横扫弧光，弩光拖尾。

## 3. 敌方技能接入友军（`add_ally_units.py`）

数据包里 Boss 和怪物的技能选目标、范围伤害都写成 `@a[...]`，只认玩家。构建末尾（所有生成器与特效收口之后）跑一遍改写：

- 单位标签：每刻最先由 `rpg:jacques_ally/units` 给玩家刷新，友军自己一直带着。
  - `rpg.unit`：全部玩家与友军。
  - `rpg.unit.ns`：不含旁观模式的玩家，加上友军。
  - `rpg.unit.nc`：不含创造模式的玩家，加上友军。
  - `rpg.unit.f`：不含旁观和创造模式的玩家（能挨打的人），加上友军。
- 敌方模块里（各 Boss、七罪领主与降临技能层 taint、罪仆、仆从、圣卫、传说怪物 entities……，名单见脚本里的 `HOSTILE`）：
  - `@a[gamemode=!spectator,gamemode=!creative,...]` 改成 `@e[tag=rpg.unit.f,...]`，其余条件原样保留。
  - `@p` 补上 `sort=nearest,limit=1`，`@r` 补上 `sort=random,limit=1`。
  - 只给玩家的参数不改，2026-11-15 的构建里约 1000 处原样保留：`tellraw`、`title`、`playsound` 的听众、`particle` 的观众、`bossbar` 的 players、`give`、`clear`、`xp`、`advancement`、对玩家物品栏的 `item` / `loot`，以及文字组件里的选择器。
  - 结果：选目标、范围伤害、打标签、计分都会把友军算进去；播报、音效、血条仍只给玩家。2026-11-15 的构建里改写了 855 处。
- 其余模块（玩家武器、契约、驱魔、符文……）：不点名的范围选择（`@e[...]` 没有正向 type / tag / scores / name / predicate 条件的）补上 `tag=!rpg.ally`，玩家的范围技能和投射物不会打到他，2026-11-15 的构建里共 324 处。
  - 例外：无主的伪爆炸（传说怪物的攻击瞬爆）照样会炸到他。
- 检查脚本的配合：
  - `check_demon_minions.py` 读取函数时，把改写后的选择器还原成 `@a[` 再判读。
  - `check_adv.py` 加了已核对的字段白名单：`player_hurt_entity` 的 `entity`。

已知的副作用（可接受）：
- 少数「按人数」的计数会把友军算进去，例如战场里有没有人、人数缩放。
- 对友军执行的 `tellraw @s` / `title @s` 之类会静默失败。
- 创造模式的玩家不再被不带游戏模式条件的旧 `@a[distance=..]` 选中；创造模式本来就不挨打。

## 4. 测试

- 无头服务器（`forceload` 区块；没有玩家时区块不跑生物，骷髅受击后的无敌时间不会倒数）：
  - 他自己找僵尸、骷髅打并打死。
  - 雅克 Boss、篡夺者、教皇战都把他当目标出招。打雅克 Boss 时，200 刻里他掉约 30 血、Boss 掉 65；篡夺者把他打到倒下；教皇战里他打死了数名圣卫。
  - 20 秒离场、倒下离场后，部件与特效都清干净。
- 测试客户端：
  - 右键誓约召唤、登场特效、走位、三连与弩光、冷却提示都正常。
  - 玩家切到创造模式时，雅克 Boss 只能选中友军，两人对打。
- 没有测：多名友军同时在场、多人联机下的主人跟随。

## 5. 调试指令

- `/function rpg:jacques_ally/give`：给自己一件誓约。
- `/function rpg:jacques_ally/debug/hand`：把誓约放到主手，替换主手原有物品。
- `/function rpg:jacques_ally/debug/summon`：召一个友军，不走冷却。
- `/function rpg:jacques_ally/debug/reset_cd`：清掉自己的誓约冷却。
- `/function rpg:jacques_ally/clear`：清掉所有友军。
