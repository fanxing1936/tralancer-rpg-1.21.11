# 七十二柱契约体系（设计草案）

状态：已实现（2026-11-06）。旧约、新约不在本次改动内，只保持接口兼容。

## 1. 现状的问题

| 问题 | 现状 |
| --- | --- |
| 获得太直接 | 书来自领取箱或裁决选项，长按一次就签好 |
| 没有成长 | 签下的第一刻就是全部内容：一条恩赐、一条枷锁、一个技能 |
| 没有义务 | 契约不要求玩家做任何事，只是每 2 秒涨 1 点魔化 |
| 其实是倒计时 | 只靠常驻沾染，约 3 分 20 秒魔化就满，再过约 1.5 到 2 分钟领主降临。签约后大约 5 分钟必定清算 |
| 战斗要切书 | 书在主手才能用，放技能就得收起武器 |
| 七十二柱是空话 | 只有七位领主能签；麾下 35 名罪仆有名字，但和契约没有关系 |

## 2. 体系总览

一份契约分四环，玩家从头走到尾：

```
立约 → 侍奉 → 深契 → 清算
 仪式    戒律    三阶    四种结局
```

书不再是技能按钮，而是这份契约的凭证：上面写着条款、阶位和契合度。

## 3. 立约

- **来源：** 保留裁决「契约」。新增柱页：罪仆按所属领主掉落，集齐同一柱五职各一页，长按合成未立约的书。领取箱保留，用于测试。
- **签约：** 长按书打开对话框（1.21.6 起的 Dialog 界面），列出恩赐、枷锁、戒律，点「签下」才生效，点「拒绝」退出。
- **祭品：** 签约时消耗该柱的材料，条款界面显示持有数量，不足时聊天栏说明缺什么。材料沿用罪仆掉落物。
- **创造模式：** 跳过祭品和深契条件，方便测试。

## 4. 侍奉：契合度与戒律

每柱有一条**供奉**（做了涨契合）和一条**禁忌**（犯了扣契合并加魔化）。契合度 0～100。

| 柱 | 供奉 | 禁忌 |
| --- | --- | --- |
| 路西法 · 傲慢 | 击杀恶魔或罪仆 | 死亡 |
| 利维坦 · 嫉妒 | 在水中或雨中杀敌 | 连续 10 分钟没碰过水 |
| 亚巴顿 · 怠惰 | 潜行静止累计时长 | 1 分钟内疾跑超过 300 格 |
| 别西卜 · 暴食 | 进食 | 饥饿值掉到 6 以下 |
| 萨麦尔 · 暴怒 | 造成伤害累计 | 连续 5 分钟没有打过人 |
| 贝利尔 · 色欲 | 承受伤害累计（献血） | 连续 5 分钟保持满血 |
| 玛门 · 贪婪 | 在契约界面献上金锭 | 经验等级低于 5 |

- 禁忌每犯一次：契合 −10，魔化 +5。
- 契合归零：掉一阶，一阶归零时魔化额外 +20。

## 5. 深契：三阶

| 阶 | 名称 | 条件 | 解锁 |
| --- | --- | --- | --- |
| 一 | 血誓 | 签约 | 现有恩赐、枷锁和力量（普通长按） |
| 二 | 魂誓 | 契合 100，献祭该柱五职的材料 | 恩赐和枷锁加深；第二技能（潜行长按） |
| 三 | 真名 | 再次契合 100，并击败过该领主 | 再加深一次；化身（潜行抬头长按） |

技能都取自领主自己的招式，继续保持「借同一位魔神的力」：

| 柱 | 一阶力量 | 二阶技能 | 三阶化身 |
| --- | --- | --- | --- |
| 路西法 | 原罪 | 失坠 | 万蛇加冕 |
| 利维坦 | 沉锚 | 逆潮 | 妒海沉城 |
| 亚巴顿 | 收割 | 停摆 | 终末收割 |
| 别西卜 | 余烬 | 蝇群 | 万蝇饕宴 |
| 萨麦尔 | 毒雾 | 血猎 | 血怒天罚 |
| 贝利尔 | 朝拜 | 顾盼 | 紫宴朝圣 |
| 玛门 | 点金 | 金牢 | 黄金终审 |

**化身：** 放出大招后进入 20 秒附身状态，属性大幅提升，结束后虚弱一段时间。冷却 3 分钟，每次魔化 +15。

**书放副手也能用：** 主手拿武器，右键放技能，战斗不用切书。主手是弓、盾这类有右键动作的物品时除外。

## 6. 魔化改动

契约不再是 5 分钟倒计时。魔化主要来自**动用力量**和**犯禁忌**：

| 来源 | 现在 | 改后 |
| --- | --- | --- |
| 立约常驻 | 每 2 秒 +1 | 每 60 秒 +1，每升一阶多 +1 |
| 玛门常驻 | 翻倍 | 保持翻倍 |
| 一阶力量 | +3 | +3 |
| 二阶技能 | 无 | +6 |
| 化身 | 无 | +15 |

魔器本身的沾染不变。

## 7. 清算：四种结局

| 结局 | 条件 | 结果 |
| --- | --- | --- |
| 夺舍 | 魔化满后走完堕落 | 现有流程，领主降临；阶位越高，降临者越强 |
| 支配（新增） | 打败从自己身上挣出的领主 | 魔化清零，保留阶位，枷锁减半 |
| 逆圣化 | 现有仪式 | 现有流程，契约烧断，获得圣痕 |
| 赦免 | 立下新约 | 现有流程，解除七柱契约 |

图腾毁约保留，作为中途退出的途径；阶位清空，代价不变。

## 8. 从契

七十二柱的内容落在这里。35 名罪仆各对应一位魔神，死亡时小概率掉落**柱印**，镶进书里成为从属契约。

- 掉率：柱页 12%，柱印 4%，都要玩家击杀。
- 二阶开 1 个槽，三阶开 2 个。
- 效果按五职划分：先锋（护甲）、猎手（远程）、司祭（回复）、咒使（减益）、处刑者（斩杀）。
- 七柱的柱印可以混用，这是玩家搭配构筑的地方。

## 10. 工程约束

- **现有接口不动：** `rpg_pact`、`rpg.pact`、`rpg_pact_cd`、书的 `custom_data`、`pact/p1..p7`、`pact/break`、`pact/burn`。依赖它们的有驱魔裁决、`[赦免]`、玛门买断、领主降临、教皇战、HUD、面板、领取箱。
- **生成器：** 七柱的表和书在 `_tools/add_pact.py`，其余在 `_tools/add_pact_depth.py`，后者排在 `add_divine_covenants.py` 之后、`make_boxes.py` 之前。
- **状态清理：** 新计分项、标签和属性全部在 `pact/break` 里清掉，逆圣化、毁约、签新约因此自动覆盖。
- **旧存档：** 已立约的玩家在下次用书时补齐阶位和契合，按一阶处理。
- **`[赦免]`：** 新约借力只用一阶力量。
- **性能：** 戒律优先用统计型计分项，逐刻逻辑放在柱位判定后面，没签那一柱不进入。
