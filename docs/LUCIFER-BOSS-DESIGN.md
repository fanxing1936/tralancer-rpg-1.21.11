# 最终 Boss 路西法 设计稿

状态：2026-11-09，前两阶段已接入（`_tools/add_lucifer_boss.py`），三阶段待做。规格对齐教皇战（`docs/POPE-DESIGN.md`），数值都是初值。

## 1. 两个路西法

用户 2026-11-09 确定：七罪恶魔领主路西法和最终 Boss 路西法是**两个不同的 Boss**。

| | 恶魔领主路西法 | 最终 Boss 路西法 |
| --- | --- | --- |
| 来源 | 签了第一柱的玩家堕落后降临（`taint/lord1`） | 只用指令召唤 |
| 阶段 | 一阶段：晨星之蛇 | 三阶段：蛇 → 知善恶树 → 古龙 |
| 血量 | 700，走驱魔系统（镇压、调查、捆绑） | 每阶段独立血条，不走驱魔 |
| 招式 | 一阶段五招、普攻和罪约（`rpg:lucifer_fight/p1/`） | 每个阶段一套，前两阶段复用已做好的招式 |
| 载体标签 | `rpg.advent` + `rpg_dm_lord=1` | `rpg.lub`，不带 `rpg.advent` |

**领主的现状：** 已改回单阶段。`morph/check` 只认 `rpg.lub`，领主打到镇压也不会变成树。罪证也只在领主身上记，最终 Boss 复用同样的招式时不给罪证。

## 2. 世界观

路西法就是伊甸园里的那条蛇，所以三个形态是「蛇 → 树 → 龙」。

- **蛇：** 晨星，傲慢，手持蛇矛。
- **树：** 蛇回到知善恶树上，树就是它。
- **龙：** 《启示录》20:2「他捉住那龙，就是古蛇，又叫魔鬼，也叫撒但，把它捆绑一千年。」

最后这句可以做击败结算的引文。`LORE.md` 里撒旦与路西法的关系还没定稿，定稿前不改 `LORE.md`。

## 3. 召唤

只用指令，在执行位置开战，战场半径 40 格，没有前置条件。

| 指令 | 用途 |
| --- | --- |
| `/function rpg:lucifer_boss/summon` | 从一阶段开始完整战斗 |
| `/function rpg:lucifer_boss/debug/stage2` | 直接从二阶段（树）开始 |
| `/function rpg:lucifer_boss/debug/stage3` | 直接从三阶段（龙）开始 |
| `/function rpg:lucifer_boss/clear` | 清除全部实体 |

## 4. 战斗流程

三个阶段，目标时长 10～14 分钟。阶段切换时无敌，避免一击跨段。

### 一阶段：晨星之蛇（生命 1000）

- **外形：** Mossy Skeleton 加 Root Rot Armor，手持蛇矛，与领主同一套模型。
- **招式：** 复用领主一阶段的普攻「刺」，以及原罪、蛇矛、高踞、失坠、王座回绝。
- **大招：** 万蛇加冕。血量到 625、375 时触发，到线前时钟走完（45 秒）也会放。

### 变身：蛇回到树上（约 5 秒）

已经做好：根须法阵、孢子光爆、蛇鳞碎片，接 Jungle Abomination 的登场动作，载体放大 2.5 倍。

### 二阶段：知善恶树（生命 1000）

- **外形：** Jungle Abomination，约 7 格高。
- **招式：** 复用已做好的碾、缠枝、禁果、诱惑、坠天、知善恶。
- **大招：** 失乐园。血量到 667、333 时触发，到线前 60 秒也会放。
- **破绽：** 缠枝全部落空时露出花心，与现有逻辑相同。

### 变身：树焚，古龙破土

演出待模型确定后再设计。

### 三阶段：古龙（生命 1500）

- **模型：** 待定，见第 8 节第 1 条。
- **招式方向：** 取材于《启示录》第 12、20 章。
  - **尾扫星辰：** 龙尾扫落天上三分之一的星辰。
  - **口吐大水：** 从口中吐出如河的水。
  - **七头十角：** 依次喷吐。
  - **天上的争战：** 最终大招。
- **击败结算：** 龙被锁链捆绑，引《启示录》20:2。

## 5. 呈现（同教皇战）

- **血条：** 新建专用 bossbar，隐藏原版条，名字换成整张位图横幅。中央饰物按阶段不同，标题用花体英文，暂定 The Morning Star、The Tree of Knowledge、The Ancient Serpent。
- **播报：** 〖路西法〗加粗；阶段切换、大招和结算带哥特体小注，按 `ART-STYLE.md` §12。
- **音乐：** 走唱片机音量，按阶段切换，放完循环，结束或清场时停止。
- **契约：** 全程带 `rpg.demon`，契约技能有效。

## 6. 技术方案

- **命名：** 战斗逻辑放 `rpg:lucifer_boss/`，生成器 `_tools/add_lucifer_boss.py`。招式继续复用 `rpg:lucifer_fight/` 的时间线。
- **载体：** 隐身卫道士，挂 `rpg.lub`，并给 `rpg_dm_lord=1`，好让两套外观认出它；不挂 `rpg.advent`，所以不走十分钟寿命和驱魔。
  - 一阶段外观的换装条件目前要求 `rpg.advent`，需要为 `rpg.lub` 加一条换装入口。
  - 二阶段外观已经只认 `rpg_dm_lord=1` 加 `rpg.lu.phase2`，可以直接用。
- **出招：** 自己的调度器，取代领主的 `advent_tick`：普攻间隔、每三次普攻接一次技能、血线和时钟触发大招，与教皇战相同。
- **失败重置：** 全员阵亡，或全员离开 40 格满 60 秒后清场。
- **血量：** 每段一池 1000，切阶段时补满。
  - 卫道士的最大生命上限是 1024，所以没法把几段的血量放进同一池。
  - 载体副手放一件隐形的、带死亡保护组件的物品。致命一击会被它吃掉，载体留下 1 血，再由阶段切换接手。一刀打过头也不会真死，也不会跨段。
  - 吃掉保护物品时会有原版不死图腾的粒子和音效。
- **读血：** 每 4 刻读一次。二阶段载体身上骑着 102 个部件，读一次血量要把它们全部序列化。
- **血条：** 原版条隐藏，名字换成柱绿的位图横幅，每 50 血一档。中央饰物和花体标题由 Codex 按 `_tools/lucifer_boss_ref/BAR-BRIEF.md` 绘制。
- **清理：** 部件、特效、召来的罪仆都打场次标签，结束时统一清除。

## 7. 开发顺序

1. 指令、载体、血条框架、失败重置、清理。
2. 一阶段：调度器接上现有招式，加大招血线。
3. 一 → 二阶段变身，二阶段调度。
4. 血条横幅和标题贴图（Codex），音乐。
5. 三阶段：模型确定后，先写 GPT 提示词，再做招式。
6. 收尾：带玩家实测、图鉴、README。

第 1～4 步不依赖龙的模型，可以先做。
