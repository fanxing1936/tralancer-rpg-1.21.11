# 来源

从《Minecraft Dungeons》本体提取（只读），经 `_tools/dungeons_conversion/generic.py` 转换。

- 网格：`Dungeons/Content/Content_DLC3/Actors/Characters/Enemies/Illagers/Mountaineer/SK_Mountaineer_01、`SM_Mountaineer_Boot`（挂 J_L_Leg）、`SM_Mountaineer_Boot`（挂 J_R_Leg）、`SM_Mountaineer_Shoulderpad`（挂 J_LArm）、`SM_Mountaineer_Shoulderpad_2`（挂 J_RArm）`
- 动作：`Mountaineer_Idle`→idle、`Mountaineer_Walk`→walk、`Mountaineer_Attack`→attack、`Mountaineer_Brace`→shoot
