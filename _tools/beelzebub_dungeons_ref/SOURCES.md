# 来源

从《Minecraft Dungeons》本体提取（只读），经 `_tools/dungeons_conversion/generic.py` 转换。

- 网格：`Dungeons/Content/Actors/Characters/Enemies/NamelessKing/SK_NamelessKing`
- 动作：`NamelessKing_Walk`→idle、`NamelessKing_Walk`→walk、`NamelessKing_TeleportIn`→cast、`NamelessKing_BasicAttack`→summon、`NamelessKing_Awake`→rise
