# 世界掉落与锻造：新物品图标

这批图标用于「世界掉落、精英怪与锻造打通」方案里新增的材料、徽记、图纸和称号。你只负责找图或画图，不改项目代码。

## 先找原图，再画

用户的要求是**能用《Minecraft Dungeons》原包里的图就用原图**。每一项都先在本机的地下城游戏包里找现成贴图（物品图标、材料图标、特效贴图都可以），找到就导出原尺寸的 PNG。实在没有合适的，再用内置 `image_gen` 画。

- 原图放进 `world_ref/art/dungeons/`，文件名用原包里的名字（例如 `T_XXX.png`）。
- 画的图放进 `world_ref/art/`，文件名用下表的「文件名」。
- 在 `world_ref/art/REPORT.md` 里，每一项写清楚：用了哪张原图（原包路径、原尺寸），或者画了几次、采用第几张。

## 硬性规则（ART-STYLE.md §4）

- 最终尺寸 **16×16**。原图不是 16×16 的，先导出原尺寸，不要自己缩放，我们来裁切和补边。
- Alpha 只有 0 或 255，不要半透明抗锯齿边。
- 光源在左上：高光在左上，阴影在右下。
- 16 网格最多 32 色，不要渐变噪点。
- 外轮廓用比本体暗两档的同色相描边，不用纯黑。
- 不要文字、边框、棋盘格底和投影。
- 风格贴近 Minecraft Dungeons 的方块像素质感。
