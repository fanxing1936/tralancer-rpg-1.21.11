# 教皇战特效贴图绘制任务

你负责绘制 Minecraft 教皇 Boss 战的特效母图。只画图，不改项目代码。

## 硬性规则

- 使用内置 `image_gen` 工具，不要用 CLI 回退，也不要用脚本、SVG、Canvas 代替绘制。
- 每个资产单独生成一次。生成后把最终图片复制到本目录的 `raw/<文件名>.png`。
- 除 `raw/` 和 `raw/REPORT.md` 外，不写任何文件，不改任何其他目录。
- 背景必须是真透明。不要棋盘格、纯色底、投影、边框、文字、水印或署名。
- 主体居中，四周留少量空白，不要裁切到边缘。
- 不要真实文字。符文只能是抽象几何记号，不用拉丁、希伯来、汉字等可读字符。
- 这些图会被缩到很小的像素网格上，所以形状要粗、对比要强、细线不能细于一个网格单元。
  每项写的「网格」就是最终尺寸：请按该网格的粗像素块来画，硬边，无抗锯齿，无模糊，无柔光，色阶少。
- 发光效果用几档硬边色块表现，外缘用棋盘式抖动点散开，不用平滑渐变。

## 风格

Minecraft Dungeons 的方块像素质感，神圣但带压迫感。

- 圣金方：白 `#FFFFFF` → `#FFF2A8` → `#FFD85A` → `#D4AF37`。
- 虚空方：白 `#FFFFFF` → `#D596F2` → 深紫。原作参考见 `Heart_Of_Ender_laser.jpg`：白色内核、紫色外缘、边缘有锯齿和方形碎屑。
