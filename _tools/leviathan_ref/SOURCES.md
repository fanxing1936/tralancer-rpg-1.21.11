# 利维坦（死灵法师）参考素材来源

原作：Minecraft Dungeons 的 Necromancer（Mojang Studios），版权归 Mojang 所有。
页面：<https://minecraft.wiki/w/Dungeons:Necromancer>（Textures 与 Sounds 两节）。Sounds 一节里
死灵法师与唤魔者共用的施法、召唤音，以及它召出的骷髅、法球命中的音效也一并取用。

文件经内置浏览器从 minecraft.wiki 的 `/images/<文件名>` 取得（站点的 Cloudflare 拒绝 curl），
按原文件名保存，逐个核对过 SHA-256。本项目开源免费、非商业，与 Mojang 无关联。
