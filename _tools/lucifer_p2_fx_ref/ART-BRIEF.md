# 路西法二阶段「知善恶树」特效母图绘制任务

你要为 Minecraft 里路西法的 Boss 二阶段绘制特效母图。这个形态是伊甸园的知善恶树，由那条蛇化成。只画图，不改项目代码。

## 硬性规则

- **工具：** 用内置 `image_gen` 生成，开透明背景。不要用 CLI 回退，也不要用脚本、SVG、Canvas 代替绘制，不要用脚本修改生成结果。
- **生成与保存：** 每个资产单独生成一次。静态图放到 `raw/<文件名>.png`，序列帧放到 `anim/<文件名>.png`。
- **写入范围：** 只写上面这些图片，以及 `raw/REPORT.md`、`anim/REPORT.md`。不改任何其他文件或目录。
- **背景：** 必须是真透明。不要棋盘格、纯色底、投影、边框、文字、水印或署名。
- **构图：** 主体居中，四周留少量空白，不要裁切到边缘。
- **画法：**
  - 这些图会被缩到很小的像素网格上。每项的「网格」就是最终尺寸，请按这个网格的粗像素块来画。
  - 硬边，不抗锯齿，不模糊，不用柔光，色阶要少。细线不能细于一个网格单元。
  - 发光用几档硬边色块表现，外缘用棋盘式抖动点散开，不用平滑渐变。
- **序列帧：**
  - 帧之间留出明显的全透明空隙，互不接触，每帧完整。
  - 所有帧的中心对齐在同一条线上。
  - 循环动画的最后一帧要能接回第一帧。

## 风格与配色

整体是 Minecraft Dungeons 的方块像素质感：腐化的丛林、古老的伊甸、带毒的诱惑。参考图在 `refs/`，只用于风格，不要复制构图：

- `jungle_abomination_views.jpg`、`jungle_abomination_texture.png`：本体的颜色和材质。深绿苔藓、暗褐树皮、品红色的发光花。
- `decal_style.png`：地面贴花的边缘处理，方块状破碎轮廓，外缘散落方块。
