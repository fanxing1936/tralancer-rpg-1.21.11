# 路西法一阶段「晨星之蛇」特效母图绘制任务

这是 Minecraft 里路西法 Boss 的一阶段。这时他还是伊甸的那条蛇：傲慢的晨星，手持蛇矛，头戴王冠，背负折断的羽翼。只画图，不改项目代码。

## 硬性规则

- **工具：** 用内置 `image_gen` 生成，开透明背景。不要用 CLI 回退，也不要用脚本、SVG、Canvas 代替绘制，不要用脚本修改生成结果。
- **生成与保存：** 每个资产单独生成一次。静态图放到 `raw/<文件名>.png`，序列帧放到 `anim/<文件名>.png`。
- **写入范围：** 只写上面这些图片，以及 `raw/REPORT-P1.md`、`anim/REPORT-P1.md`。不改任何其他文件，同目录里已有的图一律不动。
- **背景：** 必须是真透明。不要棋盘格、纯色底、投影、边框、文字、水印或署名。
- **网格：**
  - 最终贴图**只用 16×16 或 32×32**。请直接按表里的网格画，一个格子就是一个像素块，不要画比格子更细的细节。
  - 形状要简单粗壮，在 32 格里一眼能认出来。每张不超过 8 色。
  - 硬边，不抗锯齿，不模糊，不用柔光。发光用几档硬边色块，外缘用棋盘式抖动点散开。
- **序列帧：**
  - 一行横排，帧之间留出明显的全透明空隙，互不接触，每帧完整。
  - 所有帧的中心对齐在同一条线上。
  - 循环动画的最后一帧要能接回第一帧。
