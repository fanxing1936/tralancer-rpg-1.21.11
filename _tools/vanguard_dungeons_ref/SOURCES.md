# 来源

从《Minecraft Dungeons》本体提取（只读），经 `_tools/dungeons_conversion/generic.py` 转换。

- 网格：`Dungeons/Content/Actors/Characters/Enemies/SkeletonVanguard/SK_SkeletonVanguard、`SM_DesertShield`（挂 J_R_WeaponSocket）`
- 动作：`Skeleton_Vanguard_Idle`→idle、`Skeleton_Vanguard_Walk`→walk、`Skeleton_Vanguard_Attack`→attack、`Skeleton_GetHitFromTheFront`→break
