# M2 眼眉只读审查

本报告诊断的是修正前版本（SHA-256 `453284d284859b4829a0f51e0603fc0b6e6d8de1323f794f78676fe749213dcf`）。下文“当前”指诊断时状态；修正后的事实来源与结果见上级 `M2_REVIEW.md` 和本目录 `eye_fix_validation.json`。

审查输入：`pope_make_static.py` 中眼眉六个元素、原64×64贴图A01、主渲染PNG、王座正面JPEG和当前原生正面对照。没有修改模型、主脚本、原贴图或Blockbench工程。

主要错误是**横向位置太靠脸外侧**，并非左右翻转错误。当前每眼 `[3,5,6,6]` 的两黑一白确实能对应主渲染里的这一眼神；但当前几何 `|X|=2.85..5.7` 把白眼端直接贴到脸边，并与眉外缘5.7齐平。主渲染眼外缘约 `|X|=4`，眉外缘约5，眼应比眉内收约1模型单位。

## 当前六个元素

每眼有眉竖块、眉横块、眼条三个元素，两眼共六个。每个只给north面贴图，其余五面为null；同在 `Z=-3.015`、跟随head的8°整体倾斜。角色右眼翻U、左眼不翻，使白像素在眼外侧，这个镜像方向与主渲染吻合，**不应为了修位置随意再翻一次**。

| 部位 | 当前正X半脸范围 `[x0,y0,x1,y1]` | 推荐主图方案 |
|---|---|---|
| 眉竖块 | `[3.8,16.5,5.7,18.5]` | `[3,16.5,5,18.5]` |
| 眉横块 | `[1.9,15.5,5.7,16.5]` | `[1,15.5,5,16.5]` |
| 眼条 | `[2.85,14.5,5.7,15.5]` | `[1,14.5,4,15.5]` |

负X半脸对上述范围镜像。当前眼高约1与原图近似，优先修正横向位置，不必同时把眼睛横向拉大或换一套颜色。

## 原图坐标量测

主头前面四角按像素TL `(95,296)`、TR `(360,427)`、BR `(334,625)`、BL `(68,494)` 标注，以单应变换映射到12×7面；Y按现有模型头顶19.5。采样每模型单位100像素，保留原图RGB；以灰度范围区分57灰眉、37黑瞳和255白眼，7×7形态开运算只用于排除原渲染边沿细亮线，最终取最大连通片。原图角点约1–2px误差，几何/表面层深度和眉自身倾斜也会产生约0.1–0.3模型单位偏差，不能把小数位当官方坐标。

| 原主图部位 | 量到的X范围 | 量到的Y范围 |
|---|---|---|
| 角色右眼白 | `3.08..4.15` | `14.52..15.53` |
| 角色右黑瞳 | `1.21..3.11` | `14.49..15.50` |
| 角色左眼白 | `-4.04..-2.95` | `14.44..15.46` |
| 角色左黑瞳 | `-2.98..-1.06` | `14.45..15.45` |

眉横条外缘量到约+5.30/-4.75；两眉有轻微独立倾斜，且额外表面深度会偏移平面投影。圆整为眉横±1..5、眉竖±3..5，比现在外缘5.7更接近主图。完整原始/清理后数值在 `eye_analysis.json`，不是只挑有利片段。

## 两种表情必须区分

**A：主渲染表情，建议先修。** 眼条正X为1..4，其中黑瞳1..3、眼白3..4，Y=14.5..15.5。可以保留整 `[3,5,6,6]` 条只改几何坐标；如果希望眼白/瞳孔独立，则白面引用 `[5,5,6,6]`，黑面引用 `[3,5,5,6]`，颜色不改。主图明确支持每眼1白/2黑，不应把它误称成错误原素材。

**B：王座正面表情，作为另一个候选。** 截图里的白底约3×1，短黑瞳只侵入上方约0.4–0.5高，黑瞳宽约1.2并靠鼻侧。可用白底 `[1,14.5,4,15.5]`，黑瞳候选 `[1.1,15.05,2.3,15.5]`，另一侧镜像；白取原像素 `[5,5,6,6]`，黑取 `[3,5,4,6]`。这是另一眼神，不能把B和主图A当同一姿势要求逐像素一致。王座有JPEG压缩、游戏光照和少量视角差异，瞳坐标应保留约±0.2的不确定性。

A01里白眼原像素只有一格，不代表三维眼白只能占一格：原作用独立白底/黑瞳调整遮挡是与两幅参考相容的重建方式，但没有取得原mesh，不能称已确认官方拆分。只需取精确白/黑源像素，不应为了补眼白去挪用鼻顶或其他部件的白区。
