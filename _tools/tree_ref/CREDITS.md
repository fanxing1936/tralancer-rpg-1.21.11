# 主世界大树模型来源

以下树模型来自 Planet Minecraft 上公开发布的结构文件，经 `_tools/overworld_trees.py extract` 转换
（去展台底座、拆成单棵、树叶设为不腐烂、树干向下补 3 格），用于 TRALANCER RPG 主世界装饰：

- `treepack1_*`：treepack1.schem（Planet Minecraft 公开树包）
- `treepack2_*`：treepack2.schem（Planet Minecraft 公开树包）
- `castanopsis_*`：27 Castanopsis Tree, Ferns, Spruces Trees Bundle，作者 mine67（Planet Minecraft）
