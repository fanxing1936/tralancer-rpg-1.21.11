# 天使长米迦勒战：专属特效序列帧任务

内置 `image_gen` 不出 GIF，所以每个动画画成**一张序列帧图**，由我们切帧、缩到 32×32 或 16×16。只画图，不改项目代码。

## 角色

天使长米迦勒，炽天使：半透明的灵体，六只燃烧的翼，手持脊骨（一阶段）和两根肋骨（二阶段）。
他的「眼睛」是守望者——漆黑的身体上十四只圣焰橙红的眼睛。参考图在 `refs/`：
`michael_stage1.png`、`michael_stage2.png`（他本人），`michael_wings.png`（翼的贴图），
`watchling_preview.png`（守望者），`current_eye.png`（现在游戏里的眼睛，太简陋，要重画），
`impact_sheet.png`、`halo_sheet.png`（之前教皇战的特效，作为质量和像素风格的下限参考，不要照抄）。

## 硬性规则

- 使用内置 `image_gen`，开透明背景。每个资产单独生成一次，复制到 `anim/<文件名>.png`。不要用脚本生成或修改帧。
- 除 `anim/` 里的图片和 `anim/REPORT.md` 外，不写任何文件。
- 帧与帧之间必须留出明显的全透明空隙，互不接触，方便按空隙切开。每帧都要完整，不能互相裁切。
- 每帧是一个**正方形**单元，同一张图里所有帧大小相同、中心对齐在同一条线上，主体大小只随动画本身变化。
- 循环动画的最后一帧要能接回第一帧。
- 最终会缩到 32×32 像素：所以要**粗像素块、硬边、轮廓大而清楚**，细节少；无抗锯齿、无模糊、色阶少；
  发光用几档硬边色块，外缘用棋盘式抖动散开。不要文字、边框、棋盘格底、投影。
- 风格参考 Minecraft Dungeons 的方块像素质感，不要复制其中的构图或角色。

## 配色（只用这些）

- 圣焰（主色）：白 `#FFFFFF` → 暖白 `#FFF5EE` → `#FFD0BD` → `#FF805F` → 圣焰橙红 `#FF3300` → 暗烬 `#7A1600`。
- 白金（一阶段点缀）：`#FFFFFF` → `#FFF2C8` → `#F2CF7A`。
- 眼睛的轮廓和瞳孔可以用近黑 `#1A0500`。
