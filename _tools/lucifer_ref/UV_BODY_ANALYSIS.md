# Mossy Skeleton 身体 UV 核验

结论：六个基础身体方块的 UV 净区域与 Sunken 骨架兼容，可沿用下表 36 个逐面 UV；不复制 Sunken 的 coral / sprig。原图逐像素内容当然不同，不能把 alpha 不同误判成 UV 重排。正脸及原图可见的头侧面已做数值像素匹配；其余面未取得 Mojang 原始模型，仍应区分继承骨架映射与独立原作验证。

## 证据

- 两张身体贴图均为 64×32。头的 6 个面、四肢 24 个面与身体底面，31/36 个面原始 alpha 逐像素完全相同。
- 将 alpha 以 128 二值化后，身体顶面也完全相同，共 32/36 面完全相同。其余四个躯干侧面 mask 一致率见下表；差异主要在苔藓/肋骨区域。
- 正脸使用 `[8,8,16,16]`：对原作 `MCD_Mossy_Skeleton.png` 中脸部 64 个 texel 中心做仿射投影匹配，再拟合统一的每通道光照，RGB RMSE 为 0.2448 / 255。眼窝、鼻口与苔藓斑块的整套排列都参与检验。
- 原图可见头侧面使用 `[16,8,24,16]`（west）：64 点 RGB RMSE 为 0.2726 / 255；竞争的 east 镜像区域 MSE 为 24.3803，而本区域 MSE 为 0.07430。支持 side 的区域与方向，非仅凭观感认定。
- JSON 保留全部采样坐标、采样 RGB、投影参数、光照参数、原图哈希，结果可复核。

## 原图 alpha 与不做半透明的约束

`T_MossySkeleton.png` 的 alpha 统计：0×1250，255×698，254×52，1×20，2×13，3×9，9×5，37×1。原素材有 100 个非 0/255 像素，其中 52 个几乎不透明、48 个接近透明。

建议只在派生图集中用 `alpha >= 128 → 255，否则 0` 的二值 cutout；保留原文件字节不变。此举消除导出残留 alpha，并非创作半透明效果。该阈值规则应写入最终报告。

## 骨架约束

- 头 `[−4,24,−4]→[4,32,4]`；身 `[−4,12,−2]→[4,24,2]`。
- 右臂 `[4,12,−1]→[6,24,1]`，枢轴 `[5,22,0]`、rest `[40,0,0]`；左臂 `[−6,12,−1]→[−4,24,1]`，枢轴 `[−5,22,0]`、rest `[12,0,0]`。
- 右腿 `[1,0,−1]→[3,12,1]`、左腿 `[−3,0,−1]→[−1,12,1]`，枢轴分别 `[2,12,0]` 与 `[−2,12,0]`。
- 双臂和头挂 body；双腿挂 root。外层盔甲应跟随对应同一骨骼。

## 验证边界

复现：在仓库根运行 `python _tools/lucifer_ref/analyze_body_uv.py`。依赖 numpy、scipy、Pillow、matplotlib；脚本读取原始文件且不修改它们，重建 `UV_BODY_PIXEL_FITS.json` 与 `UV_BODY_PIXEL_EVIDENCE.png`。拟合随机种子固定为 42，完整参数随 JSON 保存。

- 本报告未读取原作 3D mesh，因此没有宣称每个背面或四肢面的语义都独立由原作网格确认。
- 两张参考渲染给出了正面和一侧，未提供正背面；背面最终对照应标明视角证据不足，不伪造原作背视图。
- 该分析不制作动作，也不修改 Sunken、蛇矛或共享管线。
