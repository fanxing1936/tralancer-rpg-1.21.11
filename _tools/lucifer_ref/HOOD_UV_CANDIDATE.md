模型假设：10×10×10，中心 [0,28,0]；+y向上，-z为正面。原图为64×64，坐标右/下边界不含。atlas偏移应由主任务统一加上。

## 逐面理由

### north（前 / -z）

暗脸与双眼图案可定位；眼位为 [2,24,4,25] 与 [6,24,8,25]。原作正面可见双眼及下缘暗纹。

数值检查：100/100 像素完全不透明，31种RGBA。

### west（角色左侧 / -x / 参考图可见侧）

此10×10区有71/100像素为较亮苔绿#264619，带不规则深色竖向孔隙；其密苔轮廓最接近原作可见帽侧。未做能证明唯一性的源几何对应。

数值检查：100/100 像素完全不透明，3种RGBA。

### east（角色右侧 / +x / 参考图不可见侧）

同一帽纹理上连续10×10疏苔区域，4色且无透明或洋红；以稀疏苔纹平衡左右密度。此面没有原作反向视角证明。

数值检查：100/100 像素完全不透明，4种RGBA。

### south（背 / +z）

同一帽纹理中10×10连续绿/暗绿区；主色#1A2F11和#14250D占79/100，少量亮苔呈纵向痕迹。用作帽后不会引入眼睛、洋红或根须图案。原作背面未提供。

数值检查：100/100 像素完全不透明，4种RGBA。

### up（顶 / +y）

10×8完整不透明帽上方区域，仅3种绿，含自然暗色块和少量苔纹；避开相邻区域[20,0,30,8]中的透明缺口。

数值检查：80/80 像素完全不透明，3种RGBA。

### down（底 / -y / 可见内衬）

从原图取单个确切颜色#14250D。用于低可见度内面，不把未知面标成原作底纹。若被身体完全遮蔽，应删去该面。

数值检查：1/1 像素完全不透明，1种RGBA。

## 内衬与朝向处理

- 下底/内衬原色来自 [12,1,13,2]，RGBA=(20,37,13,255)，十六进制 `#14250D`。必须复制进atlas的独立位置，不覆盖源贴图，也不借用混有其他图案的已分配区。完全隐藏的下底直接删除。
- 其余五面只采样原始PNG，未补画；均无透明像素，不会因取到空洞而漏出杂色。
- 标准方块面向使用 north=-z、south=+z、east=+x、west=-x。参考渲染右手边可见的帽侧对应角色左侧 west。
- 初版 face rotation 全为0。左右/后朝向属于候选，必须在四视角图中检查，不能只看正面判断。
- 头顶原区10×8映射10×10有明确的V伸展；没有通过悄悄扩大裁剪区域凑成10×10，避免混入透明和其他图案。
- 双眼是暗脸区域里的 [2,24,4,25] 与 [6,24,8,25]；发光按用户要求单独处理，洋红斑块仍不以ShadowTexture猜测自发光。

## 原作还原限制

该模型把原作兜帽转成同骨骼外层10×10×10方块。原作兜帽的边缘根须和开口不能仅凭一个完整方块暗脸实现；若主任务增加前缘细条，应从已列帽纹理区逐面取样并记录，不能把补做边缘说成原始几何。
