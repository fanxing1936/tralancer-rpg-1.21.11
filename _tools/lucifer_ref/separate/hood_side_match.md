# 可见兜帽侧面：有界数值匹配

只比较原作可见侧面的内区；避开远端折边和肩部遮挡。只用diffuse PNG，不用ShadowTexture，不逐像素调色。**非零残差不构成“一模一样”验收。**

## 最佳候选与现方案

最佳：原区 `[21, 9, 29, 19]`，逆时针旋转 0°，旋转后水平反转=False；RMSE **4.1706/255**。
当前 `[10,8,20,18]`、不旋转不翻转：RMSE **15.5804/255**。

最佳投影的 `ox` 与 `vy` 接近搜索上边界，说明矩形端点对预设侧面平面范围敏感。排名集中在原图 `x19..30 / y8..20`，可支持这一带比当前 `x10..20` 更符合可见纹样；**不能把最佳 `[21,9,29,19]` 当成已唯一确定的原始 UV**。本次到此停止有限搜索，不修改模型。

## 方法与限制

144个固定归一化点：s∈[0.10,0.90]，t∈[0.12,0.72]。遍历宽4/5/6/8/10、高8/10/12的连续原图矩形及8种方向，只取采样处完全不透明的候选；先固定投影排名，再对24个候选与一次12名复查进行有界仿射优化。

最佳投影 [ox,oy,ux,uy,vx,vy]：`[309.95104146254766, 89.85830881860818, 51.833103391782544, 4.49054847761618, -26.100060488115137, 173.9799115763706]`。
统一光照 slope RGB：`[1.7896151771523536, 1.6806973194696175, 1.0565472171964043]`；offset RGB：`[-12.764091565973196, -30.30219164361347, -3.840187950635979]`。

完整边界、采样位置、源RGB、原图采样RGB和预测RGB在JSON中。单次全局颜色拟合只能补偿相同面照明，不能重现原版材质。搜索是有限的，结果不能排除未测试尺寸或分片面。原图折边/下缘没有包含在本次验证，因此不能用内区匹配推导整个帽侧，更不能推导背面。
