# 来源

从《Minecraft Dungeons》本体提取（只读），经 `_tools/dungeons_conversion/generic.py` 转换。

- 网格：`Dungeons/Content/Actors/Characters/Player/Master/SK_Player_Master`
- 动作：`Player_Master_Idle`→idle、`Player_Master_Walk`→walk、`Player_Master_ShowOff`→throw、`Player_Master_Emote_HeroPose`→hero
