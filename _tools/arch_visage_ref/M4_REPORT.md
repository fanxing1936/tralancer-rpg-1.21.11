## 结构测量与可见边界

| 部位 | 直接依据 | 当前尺寸/实现 | 证据边界 |
|---|---|---|---|
| 上壳 | in_game s005 的顶面、正面、侧面角点 | 宽12、高13.943、深13.198 | 固定正交相机拟合，10点二维RMS 3.08px；深度不是独立实测 |
| 下颚 | s005 下块从嘴缘到下尖约86–100px，明显厚于HE薄颚 | 宽10.762、高8.194、深12.458 | 未照搬HE的2.8厚度；实际原几何不可得 |
| 上下嘴内面 | s020两张近竖直亮面及静态渲染的开口区域 | 各一独立发光骨，原渲染投影贴图及44原遮罩层 | 10个可见嘴/壳角点拟合RMS11.48px；局部轮廓约10–25px残差 |
| 眼与牙 | 源初段短暂亮眼及嘴缘 | 继承HE已追踪原渲染采样窗口，眼独立显隐 | 同族材质复用，不声称AV每颗牙的原像素布局全部一致 |
| 背面 | 当前源视角不可完整观察 | 星空连续包面，无额外脸纹或眼光 | 隐藏背面UV与深度为推断，四视图已提供 |

共11元素、6骨骼、**5个 item_display 部件**：上壳、下颚、眼光、上腔光、下腔光。比建议2–4多1，是因为源回仰时口内短暂变暗，而眼光仍有不同可见时段；三组发光要独立通过position藏入不透明父壳，不能合并成一个始终同亮的部件。没有scale动画。单部件包围盒通过公共管线 -16..32 检查。

## 动作与时间点

| clip/源帧 | 时间 | 依据及本次处理 |
|---|---|---|
| idle / walk | 各1秒循环 | **静态技术占位**，完全在地面下；不称原作待机或行走。无论运行时保持攻击末姿，或显式stop回idle，模型均藏在地面下。 |
| spawn_attack s000–001 | 0–0.04s | **有动图**；空白，保留。 |
| s002 / 004 / 005 | 0.08 / 0.16 / 0.20s | 上升，短暂亮眼和闭口牙带出现；按可见参考处理，未采用unused持续亮眼版。 |
| s008 | 0.32s | 第一次开口，上下颚分别运动。 |
| s012 / 016 | 0.48 / 0.64s | 上壳强回仰、眼面压薄；口内暂暗，下颚仍是向前伸出的底块。 |
| s017–020 | 0.68–0.80s | 回弹至亮口；用可见嘴内面角点消除仅轮廓拟合的翻面歧义。 |
| s020–076 | 0.80–3.04s | 持续张口；逐源帧读取轮廓重心/小幅倾斜，保留细微运动。隐藏深度与关节角为拟合推断，不声称找回原骨骼曲线。 |
| s079 / 080 / 082 | 3.16 / 3.20 / 3.28s | 收口、开始沉地。 |
| s086 / 089 / 091 | 3.44 / 3.56 / 3.64s | 逐渐只剩上壳窄条；以position沉地，不压扁模型。 |
| s092–121 | 3.68–4.84s | 最后1.20秒空白全部保留；4.88s为片尾。 |

`spawn_attack` 的参考类别为**有动图**，模型角度/位移拟合仍含推断。源25Hz对应122组姿态；工程共988个数字关键帧。公共20Hz运行时将4.88秒量化为98 ticks=**4.90秒**，多0.02秒；没有用改源时长掩盖差异。唯一允许的通道为rotation、position，插值linear。

原透明参考无法约束沿正交视线的深度平移。持续张口阶段选取该不可测自由度，让已显露的下唇保持在假想地面之上，屏幕投影不变；其余显隐由几何沉入顶面Y=0的不透明体积模拟。该地面用于预览遮挡，**不是已验证真实地形适配**。

## 材质、声音与接口

单张1024图集；黑底/紫星点继承用户已接受HE v3，未整图缩小711纹理，也未重绘星点。上下嘴面取自原 `MCD_Arch-Visage.png` 两个登记四边形，用像素中心齐次投影和最近邻采样，保留源RGBA及不规则亮形。每个元素每一面的UV、源四角、原窗口和转换链见 [atlas_regions.json](atlas_regions.json)。全亮保证暗处材质可见；无屏幕bloom、无照亮地块、无光束或粒子。

44×44原遮罩逐RGBA保存，嘴内上下两层实际使用白色有效区 `[0,2,33,44)` 并乘原HE开口截图(1105,267)的 `[255,211,255]` 常量tint。该操作通过 `emissive_masks` 元数据交给专用生成后处理；没有把颜色烘焙回原44，也没有修改公共shader。半透明与排序继承既有路径，但本Arch-Visage尚未实机看过。

9个原音效全部保留原名复制到 `sounds/`，见 [SOURCES.md](SOURCES.md)。进入片段触发现身音；0.72s蓄光攻击、0.80s口内循环音、3.28s沉地音已写入 [config.json](config.json) 的sounds/cues/enter_cues。GIF无音轨，所以这些绑定依观察到的动作阶段推断，不声称原作音画同步已经验证。Mortar声音存档但本次没有制作投射物/技能。

[config.json](config.json) 提供parts、glow、clips、seat=0、research_ground_y=0、material、emissive与声音；正式薄生成器由并行接入任务维护，本作者脚本未修改build或公共管线。建议调试召唤后直接进入spawn_attack，因为idle/walk是地下占位。嘴部/光束发射候选为上下前唇动态中点，各关键时间的模型坐标见 [sockets.json](sockets.json)；+Y向上、-Z为前，按model_scale/16换为方块，不把此候选当原作官方发射骨。

## 验证与限制

[validation.json](validation.json) 记录单图集、原44逐RGBA一致、5部件边界、3clip内存烘焙、数字通道及首序检查，错误0。该验证不等同完整项目构建/服务器检查。126张PNG哈希逐个与当前模型证据匹配；32个应空白源帧全部无可见模型像素。机读结果见 [delivery_check.json](delivery_check.json)。90个非空源帧的离线前景IoU中位数0.861，这是便于复核的投影统计，不能当视觉全部通过。

已修复两项明确可见错误：s005使用原角点标定的闭口零姿态，去掉原拟合误加的8.46°张口；眼平面按源两眼白核中心拟合，实渲染中心误差分别为0.91px、1.45px。s002原先先露出的白条实际是过早显露的眼，不是牙；眼在s004前藏入头内后，s002白像素为0。检查见 [eyes_fit.json](eyes_fit.json)、[eye_visibility_check.json](eye_visibility_check.json)。这两项修正保留s020的已校正嘴面朝向。

仍有局部10–25px边界、末端窄条、牙形和无bloom差距；背面和沿视线深度没有源多视角实证。未在真实游戏内看过。已在本机 Blockbench 5.2.2 原生打开并另存测试副本：11元素、6骨骼、3clip、988关键帧、图集RGBA及元数据保留；原生正规化/数值取整最大差异4.94×10⁻⁶，未解释差异0。主模型未被另存副本覆盖。证据见 [原生读写报告](../heart_of_ender_ref/final_validation/native_report.json)。这不是客户端视觉验证。 没有玩法、血量、技能、AI、掉落或对其他怪物的行为修改；未提交、未推送。
