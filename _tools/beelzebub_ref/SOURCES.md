# 别西卜（无名者）参考素材来源

原作：Minecraft Dungeons 的 Nameless One（Mojang Studios），版权归 Mojang 所有。
页面：<https://minecraft.wiki/w/Dungeons:Nameless_One>（Textures 与 Sounds 两节）。

文件经内置浏览器从 minecraft.wiki 的 `/images/<文件名>` 取得（站点的 Cloudflare 拒绝 curl），
按原文件名保存，逐个核对过 SHA-256。本项目开源免费、非商业，与 Mojang 无关联。
Approach、Death、Distant、WakeUp 四组原文件是立体声，游戏里不随距离衰减；其余为单声道。
