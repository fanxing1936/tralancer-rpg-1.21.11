# 城镇与地标的建筑：来源与署名

用户 2026-11-27 提供，用在主世界的城镇和地标。原件放在 `raw/`，不进仓库；仓库里只有转换后的结构（`rpg:town/*`、`rpg:landmark/*`）。

转换只做这些事：去掉展示底板和原地形，箱子等方块实体清空（换成本包的掉落表），告示牌文字与旗帜图案不保留，地基向下补几格以贴合地形；
雪原、沙漠的版本只换木材与屋顶材质。建筑造型本身不改。设计归原作者所有。
