# 序章玩家装备贴图

已完成 12 张 64 × 32 RGBA 贴图。每个角色包含 `humanoid`、`leggings`、`wings` 三层。

| 角色 | 玩家装备的像素造型 |
| --- | --- |
| 路西法 | 对照 `../concept/lucifer.png` 与已交付模型，使用Full Metal Armor 的钢灰甲板和分段结构，金饰取同套玩家鞘翅的古金色。翅膀为暗象牙灰羽、古金羽尖及少量深蛇绿。 |
| 别西卜 | 玩家装束以橄榄甲壳、分节胸板、灰质肋带、黄绿细脉和冠上绿宝石识别。蝇翼采用灰色块与硬边翅脉。 |
| 贝利尔 | 玩家装束的紫丝绸褶线、青铜 V 领和袖口、胸前两点紫眼呼应原演员。紫翼膜以青铜翼骨分区。 |
| 玛门 | 玩家装束有厚金胸甲、棕钱袋、亮金袋扣、胸链和方形腰扣。黑革翼有金边、金骨及翼尖金币。 |

`draw.py` 以原生像素坐标和固定色阶绘制三个恶魔角色与四套翅膀。概念图用于造型核对，脚本没有读取概念图像素、缩放取色或混合生成图。每种手绘材质均有五档实际可见色阶，光源为左上，采用同色相的深色描边。所有文件的 alpha 只有 0 或 255，透明像素的 RGB 同时清零。

路西法玩家甲保留全金属甲的原版纹样与钢灰色阶。脚本中的 `LUCIFER_UV` 保存从解包的 FullPlateArmor 胸甲、头盔、右臂、右腿网格正交投影获得的原纹理坐标，并将这些坐标重映射到玩家各面。原图来自已交付 `../../models/out/lucifer/atlas.png` 的 (64, 0)–(128, 64) 区域，该区域以解包的 `FullPlateArmor_Unique1/T_FullPlateArmor` 为底，序章演员的金饰取六翼羽尖色。模板要求覆盖但投影落在原图透明处的像素，取最近的原图实体像素填补。映射到玩家 UV 后，将四档金饰对应到玩家鞘翅已有的古金暗部、深影、中间色与亮面。

每张图均严格使用 `../refs/vanilla_humanoid_iron.png`、`vanilla_leggings_iron.png`、`vanilla_wings_elytra.png` 的对应 alpha 遮罩，逐字节一致。三种遮罩分别有 648、280、206 个实体像素。原模板透明位置保持透明，原模板中的孤立翼薄边像素也保留。翅膀采用标准鞘翅 UV，两片原版鞘翅镜像显示此纹理。六翼造型仍由已交付路西法模型表现。

## 重建

在安装有 Python、Pillow、NumPy 的现有环境运行 `python draw.py`。脚本仅输出本目录 12 张指定 PNG。默认输入为 `../refs/` 三张原版模板与正式交付的 `../../models/out/lucifer/atlas.png`，不依赖解包临时目录。

已重跑并比对全部 PNG 的 SHA-256，12 张字节一致。尺寸、alpha、模板透明遮罩、透明 RGB、路西法钢灰甲板与鞘翅金饰颜色来源的只读检查均通过。实际 Minecraft 装备渲染尚未进入客户端验证。

## 相对美术简报的调整

用户要求以刚完成的模型定稿为准。路西法使用定稿的深钢灰全金属甲，金饰与羽尖同色。其余三个角色保留简报的材质、配色和玩家装备布局。几何外形受原版装备和鞘翅 UV 限制，玩家装备设计中的冠尖、外扩肩甲、长袍外摆与金币挂件以贴图内的明暗和符号表现。
