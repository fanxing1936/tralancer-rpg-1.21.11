# 序章奖励「米迦勒之羽」重绘

只画图，不改项目代码；只在 `_tools/prologue_ref/art/feather/` 里写文件。

## 背景

序章结尾，天使长米迦勒升空离去，一片羽毛从天上飘落，玩家得到它作为奖励（物品名「米迦勒之羽 / Feather of Michael」，史诗稀有度，带附魔光泽）。
物品说明：「虚幻的过往，并非云烟。祂终将归来。」——它是一段过去的证物，看似虚幻却真实存在，预示米迦勒终将归来。

现在用的是米迦勒 Boss 战里的通用羽毛（`refs/feather_old.png`，16×16 放大图），画得草率：轮廓是一根直棍，羽枝没有层次，看不出是天使长的羽毛。

## 要什么

一张 **32×32** 的物品贴图 `feather.png`（透明背景，像素画，Minecraft 物品风格：深色描边、明暗分明、不做抗锯齿与半透明渐变，透明度只有 0 和 255）。

- **造型：** 一根略弯的大翎羽，羽轴从左下指向右上（与原版物品的斜放方向一致），占满画面对角线约 28 像素。羽片左右不对称，外缘有两三处自然的分叉缺口；羽根处有一小撮绒羽。
- **配色：** 米迦勒「神圣系列」的白金：羽片从羽轴处的暖白 `#FFF2C8` 过渡到边缘的桃色 `#FFD0BD`、珊瑚 `#FF805F`；羽轴是金色 `#FFD85A` 带暗金 `#A8401C` 阴影；最外沿一圈细细的圣焰橙红 `#FF3300`（序章米迦勒的特征色，只点到为止，不要整片烧起来）。
- **一点「虚幻」：** 羽片靠尖端的三四像素用更亮、更淡的颜色（接近白），像是正在化成光；不要用半透明。
- 描边用深暖棕 `#3A1A0E`，不要纯黑。

## 流程

1. 用内置 `image_gen` 画一张概念图 `concept.png`（羽毛的特写，同上配色），提示词写进 `REPORT.md`。
2. 写 Python 脚本 `draw.py`，用像素矩阵、固定坐标和离散调色板，经 Pillow 输出 `feather.png`（32×32）。概念图只作造型参考，不要缩放取色。
3. 另出一张 `preview.png`：`feather.png` 放大 8 倍，摆在深色（`#2A1A14`）和浅色（`#E8D9B0`）两种底上并排。

## 交付

`feather.png`、`draw.py`、`concept.png`、`preview.png`、`REPORT.md`（配色表、提示词、做了哪些取舍）。
