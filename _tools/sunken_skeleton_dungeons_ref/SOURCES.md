# 来源

从《Minecraft Dungeons》本体提取（只读），经 `_tools/dungeons_conversion/generic.py` 转换。

- 网格：`Dungeons/Content/Content_DLC5/Actors/Characters/Enemies/SunkenSkeleton/SK_SunkenSkeleton`
- 动作：`Skeleton_Idle`→idle、`Skeleton_Walk`→walk、`Skeleton_Vanguard_Attack`→attack、`Skeleton_BasicAttack`→shoot
